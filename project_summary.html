Project Overview

Privacy Spotlight

A desktop privacy application that tracks the user's eye movement through a webcam and keeps only the focused screen region clear, while blurring and dimming the rest of the display in real time.

Python Desktop App Built using PyQt5, OpenCV, MediaPipe, NumPy, MSS, and PyTorch.
Real-Time Tracking Uses gaze estimation, head-pose compensation, smoothing, and calibration.
GPU-Ready Blur Runs blur rendering on NVIDIA CUDA when supported, with CPU fallback.
Own Contribution Designed and implemented independently with focus on architecture, tracking, rendering, and optimization.

Project Explanation

  • I built a desktop privacy tool that creates a spotlight effect on the screen based on where the user is looking.
  • The goal was to protect private on-screen content by blurring the background while keeping the area of attention visible.
  • This project was inspired by AMD Privacy View software powered by Eyeware, and I developed my own version to understand and implement the underlying ideas.
  • I used webcam-based face and eye landmark detection to estimate gaze direction in real time.
  • I added calibration logic so the system maps raw eye movement to actual screen coordinates more accurately.
  • I implemented smoothing and prediction so the spotlight circle moves naturally instead of jittering.
  • I optimized the rendering pipeline to support NVIDIA GPU acceleration for blur processing.
  • I handled practical issues like camera angle bias, blink pauses, global hotkeys, overlay performance, and CPU fallback.
  • I completed the full architecture, implementation, debugging, optimization, and final integration of the project.
"I built this project as a privacy-focused desktop application where the screen stays clear only around the user's point of attention, and the rest of the screen gets blurred. I used Python with PyQt5 for the overlay, OpenCV and MediaPipe for face and eye tracking, and PyTorch CUDA for faster blur rendering on NVIDIA GPU. I designed the calibration flow, smoothing logic, and tracking corrections myself. The project was inspired by AMD Privacy View powered by Eyeware, and I implemented the architecture, tracking pipeline, rendering flow, debugging, and final integration in this version."

Project Flow

1. Webcam Capture The app reads frames continuously from the user's webcam.
2. Face Landmark Detection MediaPipe extracts eye, iris, and face landmarks.
3. Gaze Estimation Eye position, head pose, and calibration data are converted into a screen point.
4. Smoothing Filters and prediction reduce jitter and improve responsiveness.
5. Spotlight Rendering The system captures the screen, blurs the background, and preserves the focused circular region.
6. Overlay Display A full-screen transparent PyQt overlay displays the final privacy effect in real time.

Point-Wise Explanation

Problem Statement +

I wanted to build a system that protects user privacy on a shared or visible screen by blurring everything except the region the user is actively looking at.

Core Technologies Used +
  • Python for the overall application logic.
  • PyQt5 for full-screen overlay and hotkey-based desktop interaction.
  • OpenCV for camera handling and image processing.
  • MediaPipe Face Mesh for face landmarks and iris tracking.
  • NumPy for vector math and coordinate calculations.
  • MSS for high-speed screen capture.
  • PyTorch CUDA for GPU-based blur acceleration on NVIDIA hardware.
My Main Contributions +
  • Designed the end-to-end architecture for tracking, calibration, smoothing, rendering, and overlay control.
  • Implemented gaze mapping from webcam coordinates to screen coordinates.
  • Built a calibration system to improve real-world accuracy across the display.
  • Improved responsiveness by tuning smoothing and prediction logic.
  • Added GPU-based rendering support and fallback behavior.
  • Fixed camera-position bias for webcams placed above the monitor.
Challenges I Solved +
  • Reducing jitter while still keeping movement fast and natural.
  • Correcting the downward-bias issue caused by a top-mounted webcam.
  • Balancing performance between screen capture, blur processing, and UI updates.
  • Handling cases where GPU acceleration is unavailable and falling back cleanly to CPU.
  • Keeping the overlay responsive without capturing itself during screen grabs.
